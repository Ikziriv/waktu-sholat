# Waktu Sholat

A single-screen prayer times app for Indonesian Muslims and the diaspora. Three things, no more: the clock, the next prayer, the qibla direction. Everything else — full schedule, niat text, location and method settings — lives in drawers that slide up when you ask.

Built on the **GOTH stack**: Go, templ, Tailwind, HTMX. Ships as a web server and a Wails desktop app from the same codebase. No frontend framework, no build step beyond `templ generate` and Tailwind, no external API calls at runtime. Prayer times are computed locally with [`hablullah/go-prayer`](https://github.com/hablullah/go-prayer); qibla is a great-circle bearing from your coordinates to the Ka'bah.

> **Waktu Sholat** is Indonesian for "prayer times." The interface is in Bahasa Indonesia. The diaspora city presets (Mecca, Medina, Cairo, Istanbul, London, New York) keep it useful outside Indonesia too.

## Download

Pre-built Windows executables are published on the [Releases page](https://github.com/Ikziriv/waktu-sholat/releases):

- **`waktu-sholat.exe`** — portable web app. Double-click, it starts a local server and opens your browser to `127.0.0.1:9090`. Single file, no install.
- **`waktu-sholat-desktop.exe`** — Wails desktop app. Native 800×700 window, no browser needed. Requires WebView2 (preinstalled on Windows 10/11).

Both are self-contained: prayer times and qibla are computed locally, no external API calls, no `static/` folder needed alongside the exe.

To cut a new release, tag and push:


The `release` GitHub Actions workflow builds both exes and attaches them to the release automatically.

## Features

- **Today's schedule** — Subuh, Zuhur, Ashar, Maghrib, Isya, computed for your location and timezone.
- **Next prayer countdown** — name, time, and "dalam HH:MM:SS" until the next one.
- **Qibla bearing** — degrees from true north plus a 16-wind compass label (e.g. `295° WNW` from Jakarta).
- **Niat sholat** — Arabic, transliteration, and Indonesian translation for each of the five obligatory prayers.
- **Eight calculation methods** — MWL (default), Kemenag, ISNA, Egypt, Karachi, Umm al-Qura, Tehran, Jafari.
- **City picker or GPS** — 23 presets covering Indonesian population centers plus diaspora cities, or `navigator.geolocation` for exact coordinates.
- **Light/dark theme** — persisted in `localStorage`, respects `prefers-color-scheme`.
- **3D moon backdrop** — Three.js + GSAP, dark mode only, disabled under `prefers-reduced-motion`.
- **Desktop build** — Wails wraps the same HTTP server in a native window (800×700).

## Build

Requires Go 1.25+, Node.js (for the Tailwind CLI), and the `templ` CLI (`go install github.com/a-h/templ/cmd/templ@latest`). For the desktop build, install the [Wails CLI](https://wails.io/docs/gettingstarted/installation).

```powershell
# Generate templ files
.\build.ps1 gen

# Compile Tailwind
.\build.ps1 css

# Build the web binary (templ + tailwind + go build)
.\build.ps1 web

# Build the Wails desktop app
.\build.ps1 desktop

# Run the web server (default 127.0.0.1:9090)
.\build.ps1 run

# Run the qibla formula self-check
.\build.ps1 check

# Everything: gen + css + web
.\build.ps1 all
```

The web binary listens on `127.0.0.1:9090` by default. Override with `--addr=host:port`.

## Self-check

The only non-trivial math in the codebase is the qibla bearing. `go run . check` runs a runnable self-check that verifies the formula against three known references (Jakarta ~295°, London ~119°, New York ~58°) and confirms the Ka'bah itself resolves to ~0°. No test framework, no fixtures — one file, one command.

## How it works

1. **Location** — On first visit you pick a city or hit GPS. The choice is stored in three cookies: `ws_loc` (`lat,lng`), `ws_city` (display name), `ws_method` (calculation method id).
2. **Timezone** — The browser sends its IANA timezone via the `tz` query param on every HTMX request (`htmx:configRequest` injects it). Falls back to `Asia/Jakarta`, then UTC.
3. **Schedule** — `TodaySchedule` calls `prayer.Calculate` for the current year, finds today's row, and returns the five times in the user's timezone.
4. **Next prayer** — `nextPrayer` walks today's schedule against `time.Now()` to find the next one and formats the countdown.
5. **Qibla** — `QiblaBearing` computes the initial great-circle bearing from the user's coordinates to the Ka'bah (21.4225°N, 39.8262°E). `Cardinal` maps it to a 16-wind compass label.
6. **Clock** — `/partials/clock` is polled every 1 second via `hx-trigger="load, every 1s"`.

## Configuration

| Cookie | Purpose | Default |
|--------|---------|---------|
| `ws_loc` | `lat,lng` coordinates | none (prompts picker) |
| `ws_city` | Display name in the header | empty (shows "GPS") |
| `ws_method` | Calculation method id | `mwl` |

Method ids: `mwl`, `kemenag`, `isna`, `egypt`, `karachi`, `umm-al-qura`, `tehran`, `jafari`.
